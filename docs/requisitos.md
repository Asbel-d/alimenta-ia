# Requisitos del Proyecto ALIMENTA-IA

| ID | Requisito / Criterio de Aceptación |
| :--- | :--- |
| **RF-01** | Registrar lote con identificador único, fecha, producto y cantidades válidas. |
| **RF-02** | Calcular porcentaje de defectos = `(unidades defectuosas / unidades producidas) * 100`. |
| **RF-03** | Consultar historial de lotes y filtrar por producto. |
| **RF-04** | Mostrar un tablero con tasa de defectos y conteo de lotes. |
| **RF-05** | Marcar lotes atípicos con técnica IA y mostrar advertencia de uso orientativo. |
| **RNF-01** | No aceptar unidades negativas ni defectuosas mayores que las producidas. |
| **RNF-02** | Cada cambio integrado debe tener ticket, PR y pruebas asociadas. |
| **RNF-03** | Los resultados deben poder reproducirse con dependencias y datos de prueba versionados. |
| **RNF-04** | No incluir secretos ni datos reales sensibles en el repositorio. |
